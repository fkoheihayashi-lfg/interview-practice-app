# Interview Practice

Generate three English interview questions tailored to your target role and years of relevant experience. Practise explaining role-specific knowledge, solving practical problems, and discussing past actions and experiences.

## How to use

1. Enter your target role in **Job title** and your experience in **Years of relevant experience**. Enter `0` if you are new to the field.
2. Select **Generate 3 questions**. Answer aloud or write a draft in the optional answer field.
3. Select **Get a hint** if you need a starting point.
4. Select **Get feedback** below a written answer to receive brief feedback in English on a strength and an improvement.

Enter your years of experience as a whole number of zero or more. The app sets no upper limit, so check for typos before generating questions.

## Answer drafts and API requests

Answer drafts are kept in the current session. Selecting **Get feedback** sends the selected answer, its question, your target role, and your experience to Claude through OpenRouter. A hint request sends the question, role, and experience. Question generation first sends the job title for a separate AI safety check. Feedback first sends the selected question and answer with their role and experience for a separate AI safety check; an accepted input then receives coaching. These checks use the same Claude model through OpenRouter and add one API request and its cost to each generation or feedback action.

Editing an answer clears its previous feedback so you can request new feedback. Generating a new set clears the previous questions, hints, answer drafts, and feedback. Each action has a separate 3-second wait before repeating it, so you can request a hint or feedback immediately after generating questions. A hint is requested once per question and kept for the session.

## Run locally

To clone this repository from GitHub and use the generation features on your own computer, you need Python 3.14, `uv`, and an **OpenRouter API key**. The app connects to Claude through OpenRouter, so **an OpenAI API key cannot be used in its place**.

Open the cloned repository folder and run:

```sh
uv sync --locked
cp .env.example .env
```

Set `OPENROUTER_API_KEY` in `.env` to your OpenRouter API key. Once you have verified your billing setup, set `INTERVIEW_API_ENABLED=1`.

```sh
uv run --env-file .env streamlit run app.py
```

Open the local URL shown in the terminal. Keep the terminal process running while using the app.

## Tests

```sh
uv run python -m unittest discover -s tests -v
```

The automated tests use mocked API responses to check input validation, strict JSON schemas, safe error displays, separate action waits, answer draft retention, and cached hints and feedback.

The app sends JSON schemas generated by Pydantic in OpenRouter requests and validates the responses locally. Safety checks can still misclassify inputs. Set a provider-side spending limit for your API key; the short in-app wait resets with the session and is not a spending limit.

The question prompt combines an interviewer role with a worked example. Feedback uses examples of relevant, insufficient and unrelated answers, including equivalent paraphrases. The original five-technique comparison is recorded in [the comparison notes](docs/prompt_comparison.md).

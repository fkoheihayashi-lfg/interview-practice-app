# Implementation checklist

- [x] Three interview questions based on a role and non-negative experience.
- [x] Five distinct initial prompting techniques and saved comparison outputs.
- [x] Role prompt selected for realistic interview practice; later changes documented separately.
- [x] OpenRouter requests restricted to Anthropic with provider fallback disabled.
- [x] Strict JSON schemas generated by Pydantic and local response validation.
- [x] Job title and explicit feedback answer receive an AI safety check before coaching.
- [x] Question, hint and feedback cards use body text with escaped generated content.
- [x] Separate action waits, cached results and answer edit invalidation.
- [x] Secrets and local environments excluded from version control.

Run the tests documented in the README and exercise generation, hint retrieval and feedback from the same checkout before sharing a new version. Safety checks and few-shot examples reduce failure modes but do not establish complete attack detection or perfectly consistent assessment.
